# Multi-Omics Biostatistical Analysis & Survival Modeling in Endometriosis and EAOC
📌 **[View Interactive HTML Report](https://htmlpreview.github.io/?https://github.com/simielechiara-afk/NOME_REPO/blob/main/Biostatistics_R_project.html)**
## Background & Study Objective
Endometriosis is a chronic inflammatory gynecological disorder affecting ~10% of women of reproductive age. Although benign, it shares biological mechanisms with malignancy and poses an increased risk for **Endometriosis-Associated Ovarian Cancer (EAOC)**.

This project utilizes a high-dimensional multi-omics dataset (Gene Expression `gex`, Copy Number Variation `cnv`, and DNA Methylation `meth`) integrated with clinical outcomes to:
- Evaluate association patterns between clinical stages, molecular biomarkers (e.g., *DVL1* segment loss), and disease progression.
- Build risk stratification and prognostic survival models for EAOC progression using statistical and multi-layer clinical data.
